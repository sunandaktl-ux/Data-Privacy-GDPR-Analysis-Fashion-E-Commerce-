Data. GDPR Audit: Fashion E-Commerce Analysis

Project Overview

I looked into data privacy and GDPR compliance in fashion e-commerce. I checked over 98,000 user records to see where data might be exposed.

Key Insights

* Risk Assessment: I created a score to measure data exposure risk. This helped turn GDPR ideas into numbers.

* GDPR Compliance: I looked at user data that could identify them and threats to their privacy.

* Recommendations: I suggested limiting data access based on roles and using a data protection method to keep high-risk users safe.

Tools Used

* Python with libraries, like Matplotlib, Seaborn and Pandas.

* GDPR. Data auditing methods.
